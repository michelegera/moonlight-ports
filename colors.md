# Moonlight Color Palette

This file contains the core colors extracted from the [Moonlight VS Code theme](https://github.com/atomiks/moonlight-vscode-theme).

## Background Colors
- **Background**: `#212337` (Main editor background)
- **Lighter Background**: `#191a2a` (Darker variant)
- **Selection**: `#444a73` (Selection background)
- **Active Line**: `#2f334d` (Current line highlight)

## Foreground Colors
- **Foreground**: `#c8d3f5` (Main text color)
- **Comment**: `#7a88cf` (Comments, muted)

## Syntax Colors
- **Red**: `#ff757f` (Errors, important)
- **Orange**: `#ff995e` (Constants)
- **Yellow**: `#ffc777` (Variables, attributes)
- **Green**: `#c3e88d` (Strings)
- **Cyan/Teal**: `#86e1fc` (Properties, support)
- **Blue**: `#82aaff` (Functions, methods)
- **Sky Blue**: `#65bcff` (Keywords, built-ins)
- **Purple**: `#c099ff` (Keywords, operators)
- **Pink/Magenta**: `#fca7ea` (Tags, special)

## UI Colors
- **Border**: `#222436`
- **Accent**: `#82aaff` (Primary accent)
- **Gutter**: `#3b4261` (Line numbers, gutter)

## Grays
